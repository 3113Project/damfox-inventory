# DAMFOX Inventory - UI Guidelines

Version: 1.0

---

# Philosophy

DAMFOX Inventory is designed for people, not for database experts.

The software must feel simple, modern and intuitive.

A warehouse worker, office employee or technician must be able to use it with minimal training.

If a screen requires a manual to understand, the design is wrong.

---

# Design Principles

Every screen must be:

- Clean
- Simple
- Fast
- Consistent
- Responsive
- Accessible

---

# Golden Rules

Less is more.

Only display what is useful.

Hide advanced options until needed.

Reduce the number of clicks.

Never overwhelm the user.

---

# Navigation

Maximum 3 clicks to reach any common operation.

Menu structure must remain stable.

Use breadcrumbs when appropriate.

Always show where the user is.

---

# Dashboard

The dashboard should immediately answer:

Where am I?

What requires attention?

What changed today?

What should I do next?

---

# Forms

Forms are the heart of the application.

Rules:

Large inputs

Clear labels

Helpful placeholders

Validation while typing

Never ask unnecessary information

Required fields clearly marked

---

# Tables

Tables should support:

Sorting

Filtering

Search

Pagination

Column resize

Column visibility

Export

---

# Search

Search must be available almost everywhere.

Results should appear instantly.

Searching must be faster than navigating menus.

---

# Colors

Green

Success

Blue

Information

Orange

Warning

Red

Errors

Gray

Inactive elements

Never use color as the only indicator.

---

# Icons

Always pair icons with text.

Example

📦 Articles

🏷 Categories

🏢 Suppliers

📍 Locations

🏭 Warehouses

👤 Users

Avoid icons without labels.

---

# Buttons

Primary action

Filled button

Secondary action

Outlined button

Danger

Red button

Never display multiple primary buttons.

---

# Dialogs

Use confirmation dialogs only for destructive actions.

Deleting

Resetting

Bulk operations

Do not interrupt the user unnecessarily.

---

# Notifications

Short

Readable

Actionable

Good

Article created successfully.

Bad

Operation completed successfully.

---

# Empty States

Never show an empty table.

Instead show:

Illustration

Short explanation

Button to create the first item

Example

No categories yet.

Create your first category.

---

# Mobile

Responsive from the beginning.

The application should work on:

Desktop

Tablet

Mobile

Barcode scanner devices

---

# Accessibility

High contrast

Keyboard navigation

Visible focus

Large clickable areas

Readable font sizes

Support screen readers whenever possible.

---

# Performance

Every screen should feel instant.

Use lazy loading when necessary.

Avoid unnecessary reloads.

---

# Visual Style

Modern

Minimal

Professional

Friendly

Inspired by:

GitHub

Notion

Linear

Home Assistant

Avoid the look of old ERP systems.

---

# Future Features

Dark mode

Light mode

Theme customization

Compact mode

Large text mode

Custom dashboard widgets

---

# User Experience

The best interface is the one that requires no explanation.

Every action should feel natural.

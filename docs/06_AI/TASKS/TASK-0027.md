# TASK-0027

## Titolo

Bootstrap del frontend React/TypeScript

## Stato

Planned

## Obiettivo

Creare la fondazione eseguibile del frontend secondo `DECISION-0005`, integrata nel Docker Compose locale e collegata in modo configurabile al backend.

## Prerequisiti

- REVIEW-0026 approvata.
- Working tree pulito e branch `main` fast-forward.

## Operazioni

1. Creare `frontend/` con React, TypeScript e Vite.
2. Abilitare TypeScript strict, lint e build di produzione.
3. Aggiungere React Router e TanStack Query.
4. Creare configurazione API centralizzata tramite variabile `VITE_API_BASE_URL`.
5. Aggiungere servizio `frontend` a Docker Compose, con porta host documentata e health/readiness verificabile.
6. Configurare CORS nel backend tramite impostazione esplicita, senza wildcard in produzione.
7. Implementare una pagina minima che mostri nome applicazione e stato di connessione al backend.
8. Aggiornare architettura, README di sviluppo e changelog.
9. Aggiungere test minimi e verifiche build.
10. Creare `REVIEW-0027.md`; se approvata, sbloccare TASK-0028.

## Criteri di completamento

- `docker compose up` avvia database, backend e frontend.
- Il frontend è raggiungibile dal browser e legge lo stato del backend.
- Build TypeScript e lint sono verdi.
- Configurazione API e CORS sono documentate.
- Nessuna funzionalità business oltre al bootstrap.

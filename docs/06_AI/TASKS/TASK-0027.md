## Obiettivo

Creare la fondazione eseguibile del frontend secondo `DECISION-0005`, integrata nel Docker Compose locale e collegata in modo configurabile al backend.

## Contesto già deciso dal Tech Lead

- Stack: React + TypeScript + Vite, React Router, TanStack Query e CSS leggero.
- Il backend resta FastAPI esistente; non ridisegnare le API.
- Il frontend deve consumare una base URL configurabile.
- CORS deve essere esplicito e configurabile; niente wildcard di produzione.
- Non investigare alternative di framework o librerie: la decisione è già presa.

## Prerequisiti

## Operazioni

1. Creare `frontend/` con React, TypeScript e Vite.
2. Abilitare TypeScript strict, lint e build di produzione.
3. Aggiungere React Router e TanStack Query.
4. Creare configurazione API centralizzata tramite `VITE_API_BASE_URL`.
5. Aggiungere servizio `frontend` a Docker Compose, con porta host documentata e health/readiness verificabile.
6. Configurare CORS nel backend tramite impostazione esplicita, senza wildcard in produzione.
7. Implementare una pagina minima che mostri nome applicazione e stato di connessione al backend.
8. Aggiornare architettura, README di sviluppo e changelog solo nelle sezioni pertinenti.
9. Eseguire verifiche mirate: lint, type-check/build frontend, avvio dei servizi toccati e verifica chiamata stato backend.
10. Creare `REVIEW-0027.md` in modalità COMPACT; se approvata, sbloccare TASK-0028.

## Criteri di completamento

- `docker compose up` avvia database, backend e frontend senza introdurre regressioni evidenti nei servizi toccati.
- Il frontend è raggiungibile dal browser e legge lo stato del backend.
- Build TypeScript e lint sono verdi.
- Configurazione API e CORS sono documentate.
- Nessuna funzionalità business oltre al bootstrap.

# TASK-0024

## Titolo

Unità di misura obbligatoria per i nuovi prodotti

## Stato

Blocked

## Obiettivo

Rendere obbligatoria l’unità di misura nei nuovi payload Product senza invalidare i prodotti storici già presenti nel database.

## Prerequisiti

- `TASK-0023` completato.
- `REVIEW-0023` almeno `APPROVATO CON RISERVE`, senza problemi bloccanti.

## Perimetro

1. Rendere `unit_of_measure_id` obbligatorio in `ProductCreate`.
2. Mantenere il campo database nullable per compatibilità con righe storiche già esistenti.
3. Mantenere `ProductUpdate` parziale:
   - il campo può essere omesso;
   - un prodotto con unità assegnata non può essere riportato a `NULL` tramite API;
   - eventuali prodotti storici senza unità possono riceverla tramite PATCH.
4. Restituire 422 per creazione senza unità o con `null` e 404 per unità inesistente.
5. Documentare esplicitamente la distinzione tra compatibilità DB storica e requisito API per i nuovi prodotti.
6. Aggiungere test di regressione per Products, UnitOfMeasure, OpenAPI e payload precedentemente validi.
7. Aggiornare documentazione, changelog, stato e creare `REVIEW-0024.md`.

## Vincoli

- Non rendere `products.unit_of_measure_id` `NOT NULL` in questa tranche.
- Non eseguire backfill automatici o assegnare unità arbitrarie.
- Non introdurre unità predefinite implicite.
- Non implementare confezioni o conversioni.

## Test obbligatori

- Suite backend completa su PostgreSQL reale.
- OpenAPI: `unit_of_measure_id` richiesto in `ProductCreate`.
- Creazione senza unità: 422.
- Creazione con unità inesistente: 404.
- PATCH di prodotto storico senza unità verso unità valida: riuscita.
- PATCH con `unit_of_measure_id: null`: 422.
- `alembic check` pulito.

## Completamento e prosecuzione

Con review approvata:

- segnare `TASK-0024` come `Completed`;
- impostare `TASK-0025` come `Planned` e `current_task: TASK-0025`;
- pubblicare commit e review con push fast-forward.

## Condizioni di arresto

Fermarsi se è necessario scegliere un’unità predefinita, eseguire un backfill non documentato o modificare dati storici.

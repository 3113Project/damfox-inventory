# TASK-0026

## Titolo

Quality gate — unità di misura e catalogo

## Stato

Blocked

## Obiettivo

Validare end-to-end la tranche locale delle unità di misura e chiuderla soltanto con database, migrazioni, API, test e documentazione coerenti.

## Prerequisiti

- `TASK-0025` completato.
- `REVIEW-0025` approvata senza problemi bloccanti.

## Perimetro

1. Ricreare il database di sviluppo secondo le decisioni approvate.
2. Applicare l’intera catena Alembic da database vuoto fino a `head`.
3. Verificare downgrade alla revisione precedente all’introduzione delle unità e nuovo upgrade a `head`.
4. Eseguire l’intera suite backend.
5. Verificare regressioni su VAT, Categories, Products, Families, Barcode e ricerca catalogo.
6. Verificare CRUD UnitOfMeasure, vincoli, associazione obbligatoria sui nuovi prodotti e compatibilità delle righe storiche.
7. Verificare Swagger/OpenAPI e healthcheck/readiness.
8. Eseguire `alembic check` e `docker compose config --quiet`.
9. Correggere soltanto problemi direttamente introdotti da TASK-0023–0025 e coperti dal perimetro.
10. Creare `REVIEW-0026.md`, aggiornare roadmap, changelog, `TASK_INDEX.md` e `AI_STATE.md`.

## Verifiche minime

```bash
docker compose build --no-cache backend
docker compose up -d db backend
docker compose run --rm backend alembic upgrade head
docker compose run --rm backend python -m unittest discover -s tests -v
docker compose run --rm backend alembic check
docker compose config --quiet
```

Verificare inoltre endpoint `/`, `/docs` e `/openapi.json` con HTTP 200 e backend healthy.

## Esito

Se tutte le verifiche sono verdi:

- segnare `TASK-0026` come `Completed`;
- impostare `current_task: null` e `current_task_status: null`;
- impostare `last_completed_task: TASK-0026`;
- impostare `last_review: REVIEW-0026` con verdetto reale;
- lasciare `next_tasks: []` e `blocked_tasks: []`;
- pubblicare review e stato con push fast-forward;
- fermare la coda autonoma perché la tranche è esaurita.

## Condizioni di arresto

Fermarsi con verdetto non approvato se emergono regressioni non risolvibili nel perimetro, incoerenze Alembic, perdita di dati non autorizzata o decisioni funzionali mancanti.

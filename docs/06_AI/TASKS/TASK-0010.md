Audit tecnico delle modifiche backend locali.

## Epic

Backend Foundation

## Priorità

## Obiettivo

Analizzare tutte le modifiche backend presenti nel working tree locale senza modificarle, per determinare cosa è corretto, cosa è incompleto e quali interventi sono necessari prima di pubblicare il modulo Categories.

## Contesto

Il repository GitHub è la fonte di verità condivisa. Nel working tree locale sono presenti modifiche backend non ancora pubblicate relative a IVA, categorie, router, service, schema e configurazione Docker.

Questo task è esclusivamente di audit. Non deve produrre modifiche, commit o push.

## Operazioni da eseguire

1. Eseguire `git status --short` e identificare tutte le modifiche locali non pubblicate.
2. Leggere integralmente i documenti obbligatori.
3. Leggere tutti i file backend coinvolti e i file correlati indispensabili.
4. Confrontare il codice con la Project Constitution, gli standard di sviluppo, l'architettura e le regole di business.
5. Verificare la coerenza degli import e dei nomi dei moduli.
6. Verificare che router, schema, service e modelli rispettino la separazione delle responsabilità.
7. Verificare la registrazione dei router in `main.py` e negli `__init__.py`.
8. Verificare la coerenza tra modelli SQLAlchemy, metadata e migrazioni Alembic.
9. Verificare i timestamp ereditati, i vincoli, gli indici e le relazioni della categoria gerarchica.
10. Verificare i rischi di cicli, auto-parenting, duplicati tra fratelli ed eliminazione con figli.
11. Verificare che gli schema Pydantic distinguano Create, Update e Response e che gli update parziali siano gestiti correttamente.
12. Verificare che i service gestiscano commit, refresh, rollback e condizioni di errore in modo coerente.
13. Verificare che i router espongano codici HTTP e risposte coerenti.
14. Verificare `docker-compose.yml`, `.env`, `DATABASE_URL` e la configurazione Alembic senza esporre segreti.
15. Individuare codice duplicato, placeholder vuoti e dipendenze mancanti.
16. Non correggere alcun problema.
17. Restituire il report richiesto e fermarsi.

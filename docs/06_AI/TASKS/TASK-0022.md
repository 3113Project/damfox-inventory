# TASK-0022

## Titolo

Build backend riproducibile e readiness operativa.

## Epic

Qualità trasversale — chiusura BUG-0017-001.

## Priorità

Media.

## Stato

Blocked fino ad approvazione di REVIEW-0021.

## Obiettivo

Rendere riproducibile l’installazione delle dipendenze Python e formalizzare una readiness check affidabile per build, test e avvio locale.

## Contesto

REVIEW-0017 ha rilevato che `backend/requirements.txt` non vincola le versioni. La build corrente è riuscita, ma ricostruzioni future potrebbero installare combinazioni diverse. Lo stesso quality gate ha mostrato che i test devono attendere il completamento dell’avvio applicativo.

## Operazioni da eseguire

1. Verificare che REVIEW-0021 approvi il catalogo e autorizzi il task.
2. Rilevare le versioni effettivamente installate e verificate nell’immagine backend approvata.
3. Proporre e applicare una strategia semplice e compatibile col progetto: versioni esatte nel file requisiti oppure coppia input/lock, senza introdurre strumenti esterni non necessari.
4. Mantenere esplicite le dipendenze dirette e documentare la modalità di aggiornamento controllato.
5. Aggiungere un healthcheck/readiness check Docker o uno script minimale riutilizzabile, senza dipendenze aggiuntive, che verifichi realmente l’app prima dei test.
6. Aggiornare i comandi documentati per build pulita, migrazione, attesa readiness e suite.
7. Ricostruire senza cache e rieseguire migrazioni e suite completa.
8. Verificare che il lock/versionamento non includa pacchetti inutilizzati o dipendenze di sviluppo nel runtime, salvo motivazione.
9. Chiudere esplicitamente BUG-0017-001 nella review.

## File coinvolti

Autorizzati:

- `backend/requirements.txt` e, se scelto, un solo file lock/input aggiuntivo chiaramente documentato;
- `backend/Dockerfile`;
- `docker-compose.yml`;
- eventuale script sotto `scripts/` o `backend/scripts/`;
- test/configurazioni strettamente necessari;
- documentazione sviluppo, architettura e changelog;
- `docs/06_AI/AI_STATE.md`;
- `docs/06_AI/TASK_INDEX.md`;
- `docs/06_AI/REVIEWS/REVIEW-0022.md`.

## Vincoli

- Non cambiare framework o major version deliberatamente.
- Non aggiungere Poetry, Pipenv, uv o altri package manager senza arrestarsi e chiedere autorizzazione.
- Non introdurre CI/CD in questo task.
- Non modificare funzionalità applicative.
- La readiness non deve dipendere da tool assenti nell’immagine.

## Criteri di completamento

- Build `--no-cache` deterministica con dipendenze versionate.
- Backend avviato e health/readiness verificabile.
- Migrazioni da database vuoto riuscite.
- Suite completa verde solo dopo readiness.
- Procedura di aggiornamento dipendenze documentata.
- BUG-0017-001 chiuso.
- Nessuna regressione del catalogo.

## Test e verifiche

- build backend senza cache;
- ispezione versioni installate;
- avvio DB, migrazioni e backend;
- readiness con timeout e fallimento esplicito;
- suite backend completa;
- endpoint stato, docs e OpenAPI;
- controllo diff requisiti e assenza di dipendenze estranee.

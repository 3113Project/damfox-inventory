## Operazioni

1. Ricostruire frontend e backend senza cache quando praticabile.
2. Avviare database, backend e frontend da Docker Compose pulito.
3. Applicare tutte le migrazioni a database vuoto ed eseguire la suite backend completa.
4. Eseguire lint, type-check, test e build frontend completi.
5. Verificare manualmente e/o con test browser: stato backend, navigazione responsive, lista prodotti, ricerca, filtri, dettaglio, creazione e modifica.
6. Verificare errori di rete, 404, 409 e 422, loading ed empty state.
7. Verificare viewport desktop, tablet e mobile e navigazione da tastiera essenziale.
8. Controllare che nessun segreto, URL locale rigido o dato mock operativo sia stato pubblicato.
9. Aggiornare roadmap, architettura, changelog e stato AI.
10. Creare `REVIEW-0030.md` in modalità FULL con problemi classificati e verdetto finale.

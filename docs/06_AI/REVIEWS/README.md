# Engineering Reviews

Questa cartella contiene le revisioni tecniche prodotte durante i task DAMFOX Inventory.

Ogni review è collegata a un task e conserva:

- sintesi esecutiva;
- verdetto;
- problemi identificati;
- priorità;
- conformità a regole e standard;
- checklist;
- decisioni richieste al maintainer;
- piano di consolidamento.

## Convenzione dei nomi

`REVIEW-XXXX.md`, dove `XXXX` corrisponde al task di origine.

Esempio:

`TASK-0010.md` → `REVIEW-0010.md`

## Verdetti consentiti

- `APPROVATO`
- `APPROVATO CON RISERVE`
- `NON APPROVATO`
- `NON APPLICABILE`

Le review sono parte della memoria tecnica del progetto e devono essere pubblicate su GitHub quando il task lo consente.

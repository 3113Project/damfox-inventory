# AI Decisions

Questa cartella raccoglie decisioni operative nate dal lavoro con gli agenti AI quando richiedono tracciamento dedicato.

Le decisioni architetturali ufficiali del progetto restano in `docs/05_Project_Management/DECISIONS.md`.

I documenti di questa cartella devono sempre indicare:

- contesto;
- opzioni considerate;
- decisione del maintainer;
- conseguenze;
- task e review collegati.

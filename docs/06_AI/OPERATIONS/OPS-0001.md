## Operazioni ordinate

1. Verificare `git status` e confermare il rebase in corso.
2. Risolvere esclusivamente i due file in conflitto secondo le regole precedenti.
3. Verificare l'assenza di marcatori con:
   ```bash
   grep -R -nE '^(<<<<<<<|=======|>>>>>>>)' docs/06_AI/AI_STATE.md docs/06_AI/TASK_INDEX.md
   ```
   Il comando non deve produrre risultati.
4. Aggiungere esclusivamente i due file risolti:
   ```bash
   git add docs/06_AI/AI_STATE.md docs/06_AI/TASK_INDEX.md
   ```
5. Continuare:
   ```bash
   GIT_EDITOR=true git rebase --continue
   ```
6. Se il secondo commit genera conflitti, risolvere soltanto file documentali collegati a REVIEW-0015 mantenendo la review completa e gli stati definiti sopra.
7. Continuare finché il rebase termina.
8. Verificare:
   ```bash
   git status
   git log --oneline --decorate -6
   git diff origin/main..HEAD --check
   ```
9. Eseguire `git fetch origin main` e verificare che il push sia fast-forward.
10. Pubblicare senza force push:
    ```bash
    git push origin main
    ```
11. Ripristinare lo stash Categories una sola volta:
    ```bash
    git stash pop
    ```
12. Verificare che restino soltanto i quattro file Categories locali previsti e che il branch sia allineato a `origin/main`.

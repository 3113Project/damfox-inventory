# OPS-0002 — Allineare bootstrap e struttura operativa AI

## Stato

Planned

## Tipo

Documentation / Maintenance

## Obiettivo

Dopo il completamento di OPS-0001, allineare il repository locale alla nuova struttura AI pubblicata su GitHub e rendere operativo il bootstrap permanente senza modificare il codice applicativo.

## Prerequisito

- OPS-0001 completata;
- branch locale allineato a `origin/main`;
- nessun rebase o merge in corso;
- file Categories locali presenti ma non modificati.

## Operazioni

1. Eseguire `git fetch origin main`.
2. Leggere da `origin/main`:
   - `AGENTS.md`;
   - `docs/06_AI/AI_CONSTITUTION.md`;
   - `docs/06_AI/AI_STATE.md`;
   - `docs/06_AI/CODEX_WORKFLOW.md`;
   - `docs/06_AI/GIT_WORKFLOW.md`;
   - `docs/06_AI/OPERATIONS/README.md`;
   - `docs/06_AI/OPERATIONS/OPS_INDEX.md`.
3. Verificare che il branch locale possa avanzare in fast-forward.
4. Se il working tree contiene esclusivamente i quattro file Categories non tracciati, non eseguire pull automatico: usare il workflow sicuro approvato dal maintainer oppure fermarsi e riportare la necessità di riallineamento.
5. Verificare che, dopo l'allineamento autorizzato, siano presenti localmente:
   - `AGENTS.md`;
   - `AI_CONSTITUTION.md`;
   - `AI_STATE.md`;
   - cartella `OPERATIONS/`.
6. Verificare che il comando sintetico `Esegui TASK-XXXX` possa essere interpretato usando il bootstrap remoto senza prompt aggiuntivi.
7. Non modificare codice, migrazioni, test o Categories.

## File autorizzati

Nessuna modifica applicativa.

Sono autorizzate soltanto eventuali correzioni documentali strettamente necessarie in:

- `AGENTS.md`;
- `docs/06_AI/AI_CONSTITUTION.md`;
- `docs/06_AI/AI_STATE.md`;
- `docs/06_AI/CODEX_WORKFLOW.md`;
- `docs/06_AI/README.md`;
- `docs/06_AI/OPERATIONS/`.

## Verifiche

- `git status`;
- presenza dei file bootstrap;
- assenza di marcatori di conflitto;
- nessuna modifica ai file Categories;
- coerenza tra `AI_STATE.md`, `TASK_INDEX.md` e `OPS_INDEX.md`.

# Prompt Archive

Questa cartella può conservare prompt operativi riutilizzabili o particolarmente importanti.

I task restano la fonte ufficiale delle istruzioni eseguibili. Un prompt archiviato non sostituisce `TASKS/TASK-XXXX.md`.

Ogni prompt deve indicare:

- scopo;
- task collegato;
- versione;
- vincoli;
- stato: draft, active oppure retired.
